General

Inference Model

The selected model is used for both Model auto-scan frame extraction and automatic annotation. The built-in model is selected by default. Uploaded ONNX models must use the same 640x384 image input and [N, 5040, 21] output format.

Classes

Each class has a name (exported to YOLO) and a description (what it means, shown to annotators).

Pose Keypoints

Comma-separated keypoint names, in YOLO order. Skeleton edges connect keypoint indices (e.g. 0-1, 1-2).

Annotation Guidelines

Markdown supported. Shown to annotators on the project page.
